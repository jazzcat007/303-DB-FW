BERLIN BOY 0.12 - for the Drumboy Pro's stock bootloader (not Launch Boy)

  SD Card\        copy everything in it to the root of a FAT32 microSD card:
                    Drumboy_Pro_Fw_BB_0_12_nor.bin   the firmware (keep one Drumboy_Pro_Fw file at the card's root)
                    BerlinBoy\Samples\909, 808, 727, 606   the drum kits, read at power-on (add your own kit
                                     folders of WAVs beside them)
                    docs\Berlin-Boy-User-Guide.pdf   the guide (the box does not read it)
                  Berlin Boy makes its own BerlinBoy\Pads, Sets, MidiMaps and settings files on the card as you play.
  User Guide\     Berlin Boy 0.12 - User Guide.pdf
  Source Code\    BerlinBoy_0_12_source_8d82468.zip - the whole repo at commit 8d82468 (notagroovebox/berlin-boy)
