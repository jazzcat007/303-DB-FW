AMBIENT BOY 0.03 - for the Drumboy Pro's stock bootloader (not Launch Boy)

  SD Card\        copy everything in it to the root of a FAT32 microSD card:
                    Drumboy_Pro_Fw_AB_0_03_nor.bin   the firmware (keep one Drumboy_Pro_Fw file at the card's root)
                    AmbientBoy\                      the box's folder: it writes its seeds, knob map and recordings
                                                     there as you play (see the README.txt inside)
                    docs\Ambient-Boy-User-Guide.pdf  the guide (the box does not read it)
  User Guide\     Ambient Boy 0.03 - User Guide.pdf
  Source Code\    AmbientBoy_0_03_source_5aae6b6.zip - the whole repo at commit 5aae6b6 (notagroovebox/ambient-boy;
                  the 0.03 firmware with the licence added)
